FIGAROMN V23.7 – RÉPARATION COMPLÈTE DE L'ESPACE PROFESSEUR
================================================================

CAUSE DU BLOCAGE IDENTIFIÉE
---------------------------
L'erreur affichée :
« Erreur : async is not defined »

était provoquée par une ligne JavaScript parasite :

async
async function ...

Le premier « async » était interprété comme une variable inexistante.
Le navigateur arrêtait alors l'exécution du module professeur avant
l'initialisation des boutons et des données.

CORRECTION
----------
La ligne parasite a été supprimée et la syntaxe JavaScript complète a été
contrôlée avec Node.js.

-------------------------
L'espace professeur utilisait encore d'anciens compteurs BAC PRO :
- 6 séquences
- 36 exercices

- 7 séquences
- 42 séances / exercices

SUPABASE
--------
Les migrations déjà créées restent nécessaires pour certaines fonctions :

- MIGRATION-V23-3-SUPPRESSION-ELEVE.sql
  pour la suppression définitive d'un élève.

- MIGRATION-V23-5-HISTORIQUE-CAHIER-TEXTE.sql
  pour l'historique du cahier de texte partagé entre appareils.

Si elles ont déjà été exécutées dans Supabase, NE PAS les rejouer.

INSTALLATION GITHUB
-------------------
1. Décompresser le PATCH V23.7.
2. GitHub > Add file > Upload files.
3. Remplacer enseignant.html à la RACINE.
4. Ajouter les fichiers de sauvegarde inclus si souhaité.
5. Commit changes sur main.
6. Attendre le déploiement GitHub Pages.
7. Fermer complètement l'ancienne page professeur.
8. Rouvrir la page puis faire Ctrl+F5.

Si le navigateur est un téléphone :
- fermer l'onglet ;
- rouvrir le site ;
- si nécessaire, vider les données de site / cache du navigateur.
