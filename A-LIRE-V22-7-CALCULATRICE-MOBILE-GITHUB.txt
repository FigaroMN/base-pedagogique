FIGAROMN V22.7 – CALCULATRICE SCIENTIFIQUE MOBILE
==================================================

AMELIORATIONS TELEPHONE
-----------------------
- clavier mobile dédié et ordonné sur 4 colonnes ;
- disposition identique sur les petits écrans pour éviter le réarrangement désordonné ;
- boutons tactiles plus grands et réguliers ;
- touche = sur toute la largeur ;
- affichage du résultat sécurisé sans débordement horizontal ;
- bouton DEG/RAD compact ;
- en-tête de la calculatrice allégé sur téléphone ;
- historique lisible même avec un résultat long ;
- adaptation supplémentaire pour les écrans de 360 px et moins.

La calculatrice de bureau reste inchangée.

INSTALLATION
------------
1. Décompresser le PATCH V22.7.
2. Dans GitHub : Add file > Upload files.
3. Envoyer les fichiers à la RACINE du dépôt.
4. Remplacer les fichiers existants.
5. Commit changes sur main.
6. Attendre le déploiement GitHub Pages.
7. Sur le téléphone, fermer/réouvrir la page ou vider le cache si nécessaire.
