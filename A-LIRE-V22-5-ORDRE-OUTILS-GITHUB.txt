INSTALLATION GITHUB
-------------------
Option recommandée avec le PATCH :
1. Décompresser PATCH-V22-5-ORDRE-OUTILS-GITHUB.zip.
2. Ouvrir le dépôt FigaroMN/base-pedagogique.
3. Add file > Upload files.
4. Envoyer les fichiers décompressés à la RACINE du dépôt.
5. Accepter le remplacement des fichiers existants.
6. Commit changes sur la branche main.
7. Attendre le déploiement GitHub Pages.
8. Actualiser la page avec Ctrl+F5.

Aucune modification Supabase.
