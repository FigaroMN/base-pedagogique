INSTALLATION GITHUB
-------------------
1. Télécharger et DÉCOMPRESSER cette archive.
2. Ouvrir le dépôt :
   FigaroMN/base-pedagogique
3. Cliquer sur Add file > Upload files.
4. Envoyer TOUS les fichiers décompressés à la RACINE du dépôt.
5. Accepter le remplacement des fichiers existants.
6. Commit changes sur la branche main.
7. Attendre le déploiement GitHub Pages.
8. Tester :
   https://figaromn.github.io/base-pedagogique/index.html

IMPORTANT
---------
- Ne pas envoyer le ZIP directement dans le dépôt.
- Il faut envoyer les fichiers décompressés.
- Cette archive remplace les anciens patchs : vous n'avez plus besoin
  d'envoyer séparément les versions V4, V5 ou V6.
