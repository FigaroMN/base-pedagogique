FIGAROMN V23.5 – CORRECTION ESPACE ENSEIGNANT + HISTORIQUE CAHIER DE TEXTE
============================================================================

CORRECTION IMPORTANTE
---------------------
L'espace enseignant pouvait rester bloqué :
- la liste des élèves ne se chargeait plus ;
- les boutons étaient inactifs ;
- les classes du cahier de texte restaient vides ;
- la détection de séance ne fonctionnait pas.

La cause était une erreur JavaScript dans une fonction de réinitialisation
du mot de passe. Elle est corrigée dans cette version.

CAHIER DE TEXTE : DÉTECTION
---------------------------
La détection de séance fonctionne maintenant à partir :
1. de la progression récente des élèves de la classe ;
2. des exercices / évaluations récents ;
3. à défaut, de la dernière entrée enregistrée dans le cahier de texte.

Si aucun repère n'existe, FigaroMN propose Séquence 1 / Séance 1 et permet
une sélection manuelle.

HISTORIQUE DU CAHIER DE TEXTE
-----------------------------
Une nouvelle zone « Historique du cahier de texte » permet de :
- filtrer par niveau ;
- filtrer par classe ;
- voir la date ;
- voir la séquence et la séance ;
- rouvrir une ancienne entrée ;
- supprimer une entrée ;
- actualiser l'historique.

Le bouton « Enregistrer dans l'historique » est ajouté au cahier de texte.

SUPABASE
--------
Pour conserver l'historique entre tous les appareils, exécuter UNE FOIS :
MIGRATION-V23-5-HISTORIQUE-CAHIER-TEXTE.sql

dans Supabase > SQL Editor.

Si cette migration n'est pas encore installée, FigaroMN utilise
temporairement le stockage local du navigateur pour ne pas bloquer le travail.

FICHIERS À REMPLACER / AJOUTER
------------------------------
GitHub :
- enseignant.html

Supabase SQL Editor :
- MIGRATION-V23-5-HISTORIQUE-CAHIER-TEXTE.sql

INSTALLATION
------------
1. Décompresser le PATCH V23.5.
2. GitHub > Add file > Upload files.
3. Remplacer enseignant.html à la racine.
4. Commit changes sur main.
5. Supabase > SQL Editor :
   exécuter MIGRATION-V23-5-HISTORIQUE-CAHIER-TEXTE.sql
6. Attendre le déploiement GitHub Pages.
7. Faire Ctrl+F5 dans l'espace enseignant.

MISES À JOUR PRÉCÉDENTES
------------------------
Toutes les mises à jour cumulatives jusqu'à V23.4 sont conservées.
